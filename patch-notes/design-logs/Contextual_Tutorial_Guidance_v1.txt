Behavior
--------
- A first visit to a relevant step displays a small eight-second contextual tip. It can be dismissed. It does not dim the screen, take focus, spend cash, use redraws, or advance the calendar. The panel lets clicks pass through except for its close button.
- Tips respond to setup, first Studio Feature Store onboarding, Store branches, review browsing, Contract offer and hands, Design/Alpha/Beta selection and progress, Beta Known Bugs, four-Marketing specialization, and when to launch after testing. Beta permits launching immediately, so the initial tip guides bug search and hand selection rather than claiming the game is ready. The Contract hand view signals guidance changes when its selection or state changes.
- The priority planning dialog already explains its constraints; no toast is shown behind that dialog. When planning closes, selection guidance appears.
- Seen tip keys are stored in presentation-only RunState progress so reopening a screen or reconstructing the current phase does not auto-repeat the same tip. The footer Tip button can replay the current tip at any time.
- The existing multi-page Tutorial overlay remains available manually from the in-game footer. A new How to Play button on the Main Menu opens a separate three-page overview. Context changes no longer automatically open this blocking overlay.
- Card hover text now explains printed Scope/Core or Beta value and finite/renewable behavior. Pre-Development fields and Studio/Contract actions also explain their immediate purpose and cash/cycle boundary.
- Existing Tutorial text was corrected to distinguish zero-cycle Feature Store branch and starter purchases from later one-cycle Primitive reserve purchases.

Integration boundaries
----------------------
This is presentation-only guidance. It does not add an employee, campaign, fanbase, Promotion, save/load, accessibility settings, or gameplay rule. The broader tutorial still needs content review and playtesting, including which suggestions are useful after repeat projects and any future option to mute them. The Store retains its existing permanent first-game inline hint.
