## Approved design mechanics from the 2026-10-31 brief

- A newly created proprietary engine starts at **25 maximum Scope**, no royalties, and free support for Text, 4-Color Palette, Keyboard & Mouse and 8-Bit Sound. Creation **does not grant ownership of their Feature Store cards**. Studio Feature knowledge, per-engine support and configured project draw supply remain separate.
- Graphics, Sound, Input/Technology and Text/Design advance independently. A purchased node makes only its own branch successor challenge available immediately; no whole-generation gate blocks a branch. Challenges activate automatically for free. Purchasing a completed node uses money but no development cycle.
- An active challenge counts only printed primary and secondary Feature Core in its category from **accepted activations using that engine**. Passes and hand synergies do not count. Progress persists through phases and games per engine; purchasing the parent starts the child at zero. A completed challenge stays complete until its node is purchased.
- Scope Expansion is an automatic, free, separate milestone from the lowest **purchased** generation across all four branches: 25 starting, then30/35/40/45 at generations I/II/III/IV. The project requirement stays 30; Feature card Scope and printed Core do not change.
- Generation I's ACTIVE/TRIAL direction is +20% of the matching Feature category **toward Pass Budget generation only**, with fractional progress retained and the project's versioned 10/K8 or 2/K8 baseline preserved. Generation II's ACTIVE/TRIAL direction is +10% Graphics/Sound Pass effectiveness and −15% Technology/Design Feature bug pressure. These percentages are candidates, **not final approved balance values**.
