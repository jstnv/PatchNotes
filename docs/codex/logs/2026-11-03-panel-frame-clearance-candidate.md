# Menu panel frame clearance candidate, 2026-11-03

The user reported that menu panels interfere with the top and bottom UI, illustrated by How to Play. The candidate keeps full-window guide, Settings, and Studio setup panels clear of the decorative frame. When a visible gameplay header or footer occupies more space, guide and Settings use the larger corresponding clearance. Settings content can scroll and follows keyboard focus when available height is limited.

The isolated UI worktree was detached at `3a61522f18db7a2bae892cb8c5be1fee68cd4100`. Shared `main` was at `7c60a01cbfac76d3f3cae1062849a070b1563116` during inspection. The four relevant shared source files had no reported Git modifications when checked. Shared runtime and TODO were not edited. Existing worktree edits and `.codex-godot-temp` were preserved.

Root cause was reproduced in a focused test. The guide and the bounded folder host placed full-window panels 20 pixels from the viewport edge, while the decorative frame extends about 30 pixels. All nine geometry checks failed before the change. The candidate uses a 42-pixel frame inset and an eight-pixel gap from visible gameplay HUD controls. It changes `folder_ui.gd`, `how_to_play_guide.gd`, `demo_settings_menu.gd`, and `main_menu.gd`, and adds `verify_frame_safe_panels.gd`. The shared-derived four-file candidate and exact pre-edit source are pinned in the [evidence manifest](../findings/panel-frame-safe-20261103-v1/manifest.json). The [scoped patch](../findings/panel-frame-safe-20261103-v1/frame-safe.patch) passed forward and reverse applicability checks against those snapshots. Reconcile it against current shared source before adoption.

The local candidate passed 21/21 focused geometry and focus checks in both native and headless runs across 1152×648, 1280×720, and 1920×1080. Those checks cover title panels, visible gameplay HUD clearance, and Settings Apply/Reset focus following the scroll. A native compatibility fixture using the newer shared guide source passed 15/15 geometry checks. Its guided-tour catalog was stubbed because the isolated older project lacks that dependency. Its [1280×720 guide render](../findings/panel-frame-safe-20261103-v1/current-guide-1280.png) demonstrates the clearance; other dependencies remain from the isolated project.

The maintained Settings verifier passed 29 checks with zero failures. Title-to-Settings motion passed 14/14, and panel transition padding passed 27/27. The older full How to Play verifier stopped at an invalid save-fixture payload and timed out. UI folder navigation completed 101 checks with one failure in the normal Studio-only save/navigation assertion after the Create action. Those broader save-path failures remain unresolved and are retained in the evidence folder. Do not infer current shared-build acceptance, release readiness, or physical-controller coverage from this candidate.
