## Design conclusion and next evidence

**Do not adopt the Review-only one-versus-two gate.** One card already delivers the same five historical 8+ titles in this four-seed panel while retaining one more pre-1980 game. Two cards can produce a 9.0 and help a weak first game, so the second purchase should be an optional **OPEN** prospective decision based on attainable four-Core gain, full-project affordability and remaining pre-1980 calendar, not a fixed Review threshold. The current `full_pool` baseline also generated first games at 5.7 and 8.0, so the next design study should address the first-release provisional scoring profile and generated four-Core standards before certifying any opening tape. Rebase the paid Store graph and quotes against current source, then test all eight Genre specialists, typed January archives, active post-start market/sales and eight-rival CPU/save. Trial $25,000, target vector, purchase gate and cohort selection remain **OPEN**. This finding does not queue implementation or approve balance.
