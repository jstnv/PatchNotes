It records **116 decisions**, including **71 Design/Alpha Feature hands**, **five ordinary redraws**, and **twelve Design/Alpha exit requests**. Every recorded Design/Alpha exit request had **zero visible and zero undrawn Features**; each Alpha exit had played Scope 35/30. All four Beta launches had 35/30. The five redraws occurred with undrawn supply present, so this run exercised the hidden-Feature search. It did not exercise a Pass-only search, unaffordable hidden Feature, irrecoverable project or an old save.

The [B v1 fresh-process replay](sims/whole-supply-gates-20261026-B-replay01/replay-report.json) passed all 18 player fixture steps with matching final state/RNG. The v3 world run independently reproduced v1 seed4423's releases and checkpoints. The world probe advances a clock-only player, so **player Review/sales and active market pressure were not measured**. The world processes took about 3.1–3.3 seconds each after isolated import; shared-host timing with two rivals is not a population CPU budget. Source-matched authoritative guard rejection, Studio-only Continue, longer campaigns, release-EXE and human acceptance were **NOT RUN**.

## Interpretation and next test

Keep both qualitative rules: exhaust possible phase Features and never publish below full played Scope. This roster/policy combination can produce a 6.x Arcade opening game by ordinary hands, but it leaves Wayfinder weak and may reduce competing title count. Before an adoption handoff, test current-source legal admission/supply, actual authoritative Alpha/Beta/launch rejection, hidden-draw and Pass-only search, low cash and blocked recovery, Studio-only Continue, longer/populated campaigns, player Market/sales and CPU. A source-pinned comparison against the current canonical rules must regenerate legal starts; no old checkpoint should be transferred between revisions. No numerical roster, search allowance, balance or gameplay adoption is approved by this finding.
