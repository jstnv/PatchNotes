# First release generates each Genre's standards — 2026-10-26

**Status: USER-DIRECTED qualitative design; numerical rule and implementation OPEN.** This supersedes the fixed 7.0 founding Review and any pre-authored persistent 1977 Genre standard in [v1](2026-10-26-eight-genre-1977-opening-direction-v1.md). Eight rivals, one permanent specialist per live Genre, still begin their histories in 1977 and pursue legal specialty-directed Store growth.

## Selected sequence

1. Before the first release in a Genre, that Genre has **no established market benchmark**. A provisional, lower *scoring profile* is still needed to evaluate the first game's four Core scores under the shared Review formula. It is bootstrap scoring input, not a historical release or a persistent market standard. Its exact four values and whether profiles differ by Genre are OPEN.
2. Each specialist's first 1977 game is developed from a legal, funded Feature supply and actual Design/Alpha/Beta work. The desired first Reviews are **6.0–7.0 inclusive**, replacing the prior guaranteed 7.0. A first game's Review is calculated from its frozen provisional profile, played Scope, Bugs and variance. Do not rewrite the Review or four Core scores after release to hit that range. A historical generator or validated tape that cannot consistently produce the range needs design revision; the range alone is not a license for a rating clamp.
3. On the first actual committed release in that Genre, capture its dated **Graphics, Sound, Technology and Design output** plus its Review and provenance. Generate that Genre's first persistent four-category market standard **from this released performance**. A scalar Review by itself cannot determine four category targets. The transformation, minimum/floor, rounding and whether Review quality modifies the Core-derived vector are OPEN; no direct `standards = cores` formula is approved.
4. The generated standard becomes available only to projects that **begin after its effective boundary**. Recommend the following month, consistent with the existing monthly Market snapshot, so simultaneous releases have an unambiguous order. Already begun projects retain their frozen provisional or previous standards; published Reviews never change. Exact effective-boundary policy is OPEN until the market model is tested.
5. Later 1977–79 releases may raise the relevant Genre standard through a separate, dated progression rule. By January 1980, retain the generated benchmark and history as a versioned opening snapshot. Old titles remain frozen historical records: they earn no post-start sales/Fans and do not count as recent live Genre/Theme saturation. Historical benchmark influence, if selected, is a distinct explicit path from live Market facts.

## Reconciliation and alternatives

The present ACTIVE/TRIAL 1980 table is a fixed base profile for all eight Genres. The proposed 1977 bootstrap plus first-release generation is a **new design revision**, not a reinterpretation of that runtime table. Current `MarketTransactionTrial.targets()` gets its benchmark only from recent active same-Genre releases with Review at least 7.0 and four Core scores; the proposed 6.x historical first game and frozen archive cannot use that path unchanged. A versioned historical benchmark source, target snapshot and migration are required. The first 6.0–6.9 title can establish a standard under this new rule even though it does not meet the current live 7.0 strong-Core gate.

| Alternative | Status |
| --- | --- |
| Authored exact 7.0 first title seeds standards. | SUPERSEDED by the user's 6.0–7.0 first-release direction. |
| Set permanent standards before a Genre has any release. | Rejected for this opening design; use only a provisional scoring profile until the first release. |
| Use Review alone to generate four Core standards. | Insufficient information; retain the actual four-Core output. |
| Insert historical titles into live release facts to reuse the current gate. | Rejected by frozen historical accounting and saturation separation. |
| Force first Review into range by clamping the final result. | Not selected; preserve ordinary scoring and validate the opening recipe. |

## Next evidence gate

Predeclare and test at least the current two-rival baseline, an eight-specialist 1977 career with provisional scoring/first-release standard generation, and a no-historical-benchmark control. Test candidate four-Core transformations and the following-month effective boundary in separate versioned private variants or a read-only arithmetic screen before gameplay adoption. For each Genre and seed report first actual Review, Scope/Bugs/Core, provisional profile, generated standard, later frozen project standard and Review, January 1980 benchmark, player first Review, publication cadence, finance, replay/Continue, CPU and failures. A generated first title outside 6.0–7.0 is a failed opening case, not a reason to change seeds silently. January 1980 target strength and the user's usual first-player-game ceiling remain empirical checks.
