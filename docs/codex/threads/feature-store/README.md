## Working agreement

1. Capture questions, alternatives, evidence, and proposed work in [working-notes.md](working-notes.md). Keep unruled proposals **OPEN**; findings and candidate numbers do not approve gameplay.
2. Record agreed Store rules and rationale in [the system design](../../design/feature-store-progression.md). Put cross-system rulings in [DECISIONS.md](../../DECISIONS.md) when relevant.
3. Keep the internal [TODO](../../TODO.md) unchanged until the user explicitly prompts a contribution. Then turn agreed design work and unresolved prerequisites into scoped tasks with acceptance checks.

Current ownership, parent unlocks, familiarity discounts, Primitive pricing, and one-cycle later purchases are described in the [system design](../../design/feature-store-progression.md). Later-era content, complementary progression gates, multi-parent mechanics, and later-card play fees remain open. The current implementation and verification limits are summarized in [CURRENT_STATE](../../CURRENT_STATE.md).

**Current design status:** the user approved **Sub-Areas' identical-to-Levels printed stats and distinct finite ID for a bounded design pilot**, an [ACTIVE/TRIAL evaluation standard](DECISION-v1-optional-upgrade-standard.md), and—after delegating the evidence-based recommendation—a [Store-only, no-hard-Levels-parent access rule](DECISION-v2-sub-areas-access.md) for the pilot. The [24-route parent comparison](FINDINGS-v8-sub-areas-parent-rule.md) found that the required Levels chain denied child purchase in three of four Strategy routes at the trial quote; the independent node improved access but one buyer still blocked financially. A [four-route one-release deferral probe](FINDINGS-v9-sub-areas-one-release-deferral.md) found only two delayed $1,700 buyers, one with rent arrears. A new [48-route Strategy reserve screen](FINDINGS-v10-sub-areas-reserve-screen.md) found quote-only buying caused three added financial failures across two genuine startup ledgers; a $1,000 post-quote floor avoided added failures but allowed only one distinct seed/policy buyer, and $5,000 allowed none. Price, play fee, numerical pass threshold, purchase trigger, first-era availability, UI and gameplay rollout remain **OPEN**; Background Music remains a candidate. The shared Task 2 comparison still needs cross-specialty/live-node/Background Music historical work and post-Game-5 settled-sales evidence. The earlier [timing](FINDINGS-v5-timing-pilot.md), [Game 5 payoff](FINDINGS-v6-sub-areas-payoff.md) and [$0/$50/$90 fee overlay](FINDINGS-v7-sub-areas-fee-sensitivity.md) remain bounded evidence, not numerical approvals.
