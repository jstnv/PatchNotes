## Evidence by assignment

| Proposal | Supported by evidence | Still unverified |
|---|---|---|
| Balanced Craft Brief | Private completion/balance runtime and legal full/partial/zero witnesses; selected-hand explanation can distinguish provisional versus final standing | Current Search source, poor/fresh access, broader rosters, adoption gates and numerical approval |
| Compact Feature Package | Canonical `evaluate_profile` supports multiple distinct challenge kinds and takes the minimum grade; balance and Scope ceiling already exist | New registered template, frozen terms, coherent targets, legal attainability, payable settlement and display |
| Commissioned Original | Existing SideStreet commission architecture provides a reference for invitation, preparation, ownership and delivery | Crown qualification/fee/Review/standing terms, Crown routes, migration and playable acceptance |

Capability is not a data-only adoption guarantee. `terms_for_contract` currently special-cases SideStreet Brief to zero its cash/Promotion caps; adding a Crown Brief ID without auditing that routing could assign the wrong reward categories. The canonical evaluator accepts one to four distinct valid kinds and rejects duplicate kinds. That supports the proposed cash composite mechanically, but does not register or approve it. Reuse existing fixed-point/integer rounding, frozen accepted terms and settlement boundaries if a later implementation is authorized.

The cash package's Scope ceiling must permit full completion, and the legal owned card pool must support the combined objective within its hands. Scalar compatibility alone cannot establish accessibility. Its base completion and challenge bonus remain separate; avoid implying that a challenge miss forfeits base earnings.

Full-game commissions should retain normal Genre-weighted scoring. Crown's short-work raw-Core balance identity does not justify imposing equal raw game Cores on Genres with different score proportions. This is a design recommendation; it is not new measured commission performance.
