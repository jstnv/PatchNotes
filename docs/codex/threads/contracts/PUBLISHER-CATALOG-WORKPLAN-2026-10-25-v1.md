# Searchable publisher catalog — parallel design workplan

2026-10-25. **DESIGN review / proposed content; no gameplay queue or new numerical approval.** User asks what this Contracts thread can work on while Search is implemented. Recommended priority: authored publisher work templates, starting with Crown, using the queued search interface without changing its transaction rules.

## Why this next

Search provides a repeatable way to obtain work. The next content question is what each publisher asks the player to do, and what greater trust unlocks. That can be specified without touching PN Implementation's current files, adjusting rewards or reopening redraw strategy. Crown already has balanced-Core identity, a private Reputation Brief, legal partial/full/zero examples and a proposed selected-hand preview; those provide the strongest starting evidence.

Investment-based support remains separate from searchable Reputation-gated work.

## Deliverables in this thread

1. **Crown authored template sheet first:** working name, publisher identity, cash work versus Reputation Brief versus commission, player objective, challenge mechanic, prerequisites, success/partial/zero explanation, reusable evaluator, and unknown decisions. Avoid several different names for mechanically identical work.
2. **Qualitative progression map:** what a new contact entrusts, what a trusted partner can take on, and what established partners might unlock. Describe changed responsibility/complexity; leave numeric Reputation thresholds, durations, rewards and rollout OPEN unless current authority already supplies them.
3. **Reusable content checklist:** legal finite card pool, reachable objectives, score preview wording, early-versus-final information, no hidden full-result prerequisite, capped standing, owned offer persistence and no unapproved new reward source. Reuse existing challenge families before proposing new mechanics.
4. **Later Neon/Starwave sheets:** use the same format after Crown's content identity is coherent. No implementation dependency on these sheets; Search can ship its approved first catalog independently.
5. **Post-search experiment plan:** prepare questions and comparisons now; pin concrete seeds/bounds/source and run only after the accepted search source is available. Include Contract-led progression and low-resource starts rather than reusing only post-unlock wealthy states.

## Constraints and decision status

The user approved search cost, replacement cadence, preservation of old offers and commissioned games at existing gates. These do not approve arbitrary new difficulty combinations, numeric tiers, offer randomness, expiry/decline mechanics, reward multipliers, longer hands or repeatable introductory advances.

The recommendation is **hand-authored templates selected from an eligible catalog** for initial content design. Whether future searches select randomly among several templates, offer a board of choices or allow an exact job choice needs its own decision; do not change the implementing one-offer search flow now. Preserve the proposed exact-card Crown preview and parked redraw research. Rewards remain unchanged throughout this design pass.

A reviewer should be able to explain what makes each proposed Crown assignment distinct, what information the player sees before paying to search/accepting/playing, which current evaluator supports it, and which open terms prevent activation. Produce a versioned proposal and acceptance sheet; label existing approved facts versus new candidates. Numerical or human-play conclusions require their corresponding evidence, not merely a compelling template name.
