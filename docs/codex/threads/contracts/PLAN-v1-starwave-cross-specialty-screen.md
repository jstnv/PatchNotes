## Question and source gate

Can each current Genre specialty earn a legal Starwave offer and complete its three hands with its own roster, and does any legal route encounter a blocked useful action or an original overdue bill before the completing-hand receipt? This is a reachability and liquidity screen, not a search for a preferred cap or final balance.

Start from the [native-v3 implementation manifest](../../findings/starwave-implementation-v1/source-manifest-v3.json) only if it still matches the frozen runtime; otherwise create a separately labeled source revision. Do not edit gameplay code, maintained tests, assets, configuration, the shared To Do List or implementation authority. Never mix results from different source snapshots. A failed integrated gate must be identified and kept separate from a design route's result.

1. Use the eight locked specialty rosters in [Genre specialty authority](../../design/genre-specialties.md): Action, Adventure, Role-Playing, Strategy, Simulation, Puzzle, Sports and Racing. Use an explicitly recorded fixed seed/policy for each; seed 1104 is the primary control because the current Action native route earned the offer. Allow one declared fallback seed (4417) only after a documented failed first attempt. Maximum 16 legal foundation attempts. Keep the same chosen traits and deterministic card-selection/spend policy where legal; record every policy adaptation forced by roster availability, rather than silently replacing a failed route. 2. Earn two distinct releases and three distinct completed Ironclad/Crown/Neon Contracts through actual native actions. Do not inject unlocks, offers, cash, debt, sales or hand outcomes. For every attempt, record the first blocked action, cash low point, original arrears, credit, release Reviews/Awareness, owned Primitive IDs and exact reason an offer was or was not earned. An ineligible route is an outcome, not a simulated Starwave completion.
3. On each earned offer, freeze the actual eligible pool and run the approved live three-hand $0 pilot. Record draw/retention IDs, exhausted Features, Pass reuse, Scope/Core half-units, completion numerator, exact receipt, productive cycles and cash/bills before acceptance and after each hand. Preserve existing Bank/payroll/rent/sales order and Neon/Crown Promotion. Compare the same checkpoint to legally starting the next game without Starwave at common calendar boundaries; report next-project progress and settled portfolio cash separately.
4. Classify a cash-rescue candidate only when a real legal action is blocked for lack of cash or an original due bill remains unpaid during the acceptance-to-hand3 window. Low cash by itself is not rescue evidence. If no route meets that condition within the declared attempts, stop and report the limit. If one does, prepare a **separate analysis-only** advance comparison with a fixed $2,240 total cap, identical observed hands and exact lower completion remainder. Predeclare small candidate advances and independently reconcile finance before drawing a recommendation; the current $0 trial stays approved until a later user ruling.
