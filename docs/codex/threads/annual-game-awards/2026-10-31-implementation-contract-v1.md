## Resolved rules

- First new-world eligible year:1980. Existing worlds without the ledger start with the current year only when before December Week2; at/past its boundary, begin next year without retroactive results or payouts. Saved current results/stages never recompute on Continue.
- Trigger: once the complete productive world transaction first reaches December Week2, after actual player effects, rival commands/post-boundary launches and royalty settlement commit. Include actual current-year releases committed by that snapshot, including rival releases committed within that transaction. A later zero-cycle player release at the same displayed week occurs after the cutoff and is excluded. This is a committed-event cutoff, not the whole Week2 interval; publish that definition in the ceremony. Use the central Clock with migrated owner offsets. No UI timer or animation decides eligibility.
- Studio awards: active cohort Studios with at least one eligible current-year release. Gross Fans earned is the sum of actual positive monthly recruitment through cutoff, excluding founding grants and award gifts; losses do not subtract. Studio of the Year uses Fans before this ceremony's payouts.
- Game ranking: frozen exact category Core integers and exact released Review tenths. Descending score, then ascending textual Studio ID, then ascending release ID. No sales/units tie influence. Equal scores are explicitly shown with the stable-ID tie rule.
- Up to3 real nominees in each of7 awards; preserve order Graphics, Sound, Technology, Design, Rising Studio, Studio of the Year, GOTY. No fabricated contender. A Studio may have multiple game nominations and multiple wins.
- Each nominee entry grants10 Fans. Each first-place entry grants an additional40 Fans and5 banked Awareness. Stack additively per nomination/win across all awards; no arbitrary cap beyond checked integer bounds. Fan/Promotion plans for every owner preflight before any mutation. Same accounting for AI/player. No cash, retroactive sales, or edits to frozen existing releases.
- A chronological owner receipt records year, owner cycle, nominations, wins, Fan/Awareness totals and releases already committed at that cycle before the award. Fan replay and Promotion validation must distinguish before/after-award same-cycle launches. Bank consumed only by the next successful release, never failed/canceled launch or presentation.
- Global world ledger owns versioned frozen inputs/results/rewards and presentation stages. Before playback, the full result and payouts must be in the next durable Studio checkpoint. During production, keep the result pending until Studio; never add a production Continue save. Presentation progress is durably saved before advancing a page.
- Ten stages: intro, overview,7 awards,final. First ceremony in each world must visit every stage. Later ceremonies allow Skip to results. A persistent Settings preference may skip future presentations, but never the world's first ceremony and never accounting. Show the preference in Settings with that explanation and beside Exit at final results. Escape/controller B cannot abandon mandatory viewing; OS close uses existing Studio save/quit. Resume the exact saved stage/rankings.
