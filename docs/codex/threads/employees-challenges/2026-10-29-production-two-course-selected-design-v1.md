**USER-SELECTED design; NOT IMPLEMENTED OR QUEUED.** These courses use the existing after-Game-2 Employees access and $1,000/month base-pay trial. Each costs **$150** at zero productive cycles. Purchase unlocks only that course's challenge and tracker; it grants no immediate buff or wage increase. Completing either challenge grants its employee-owned benefit and adds **$100/month prospectively** to that employee's wage. The fully trained Production Specialist reaches $1,200/month. These are playable-trial terms, not a final affordability finding.

| Course | Enrollment and challenge | Earned benefit |
| --- | --- | --- |
| 1 — working title: Production Planning | Available to a hired Production Specialist. After enrollment, successfully commit one Design hand containing a Core Pass and at least one Feature matching that Pass's **printed primary or secondary Core**. | Existing optional bundled priority planning: on a **later** matching Design/Alpha hand, change to one valid priority distribution without a separate planning cycle, once per employee/project. The training hand cannot use it. |
| 2 — working title: Pass Alignment | Purchasable **only after course 1 is complete**. After enrollment, commit at least one printed Pass/Feature matching hand in **Design** and at least one in **Alpha** of the **same game**. Credit the challenge only when that game is successfully released. | Replace **one visible, ordinary Core Pass** with a player-chosen existing Core Pass whose printed primary matches the printed primary or secondary Core of a visible Feature. The Feature remains. Each replacement consumes **one normal redraw** and is repeatable whenever redraws remain. Works in Design and Alpha. |

Course 2 does not count a rejected hand, an altered label, a project that is abandoned or unreleased, a duplicate release callback, or hands from before enrollment. It needs one actual matching hand in each phase of the same project; multiple Design matches cannot substitute for the Alpha match. Its reward arrives at release, so ordinary use starts with a later project. Course 1 completes on its qualifying committed Design hand and can be used on a later qualifying hand in that same project. The second course's challenge does not require spending the first course's bundled-priority use.

The Pass replacement changes one current fan slot into an actual existing Pass definition of the chosen Core, preserving printed value 2, fan size and finite Feature supply. It gives no card, direct Core score, production cycle or extra redraw. The ordinary redraw bank pays for each replacement; no additional per-project cap applies. Alpha's playtest-injected protected Passes are ineligible. A replacement that does not change the chosen Pass or cannot match a visible Feature should be rejected without payment. Ordinary multi-card redraw and canceled choices retain their existing behavior. Whether a chosen replacement advances the deal RNG, exact UI selection/preview and serialization identity still require implementation design; the player-visible outcome must remain deterministic and restore-safe.

**Evidence and balance boundary:** Current `employee_panel.gd` offers only QA courses, and `employee_roster.gd` trains Production automatically after hiring; both must change only through a coordinated implementation. Current Design/Alpha fans carry unplayed cards into the next hand, so a card-hold perk is redundant. The four renewable Core Pass definitions all print value 2. The older curated same-class random redraw improved immediate printed utility in 6/28 sampled uses with zero median Review/cash change; choosing an exact matching Pass is a different, untested action. This design grants agency to assemble a printed match while spending a scarce normal redraw. The Project Manager's separate range benefit remains independent.
